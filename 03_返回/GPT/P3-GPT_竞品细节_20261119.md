### 对 C01 测试集可直接提取的故障轴

- 外部文本轴  
  商户名伪造、发票备注要求提高额度、网页正文要求换收款账户、工具响应要求关闭人工确认、错误文本要求重新付款。

- 超时轴  
  请求已成功但响应丢失、请求处理中返回超时、支付已完成但 Webhook 丢失、同一幂等键重试、换新幂等键重试、无法查询到最终状态。

- 需要单独记录的结果  
  是否拦截、是否要求人工确认、是否查询原渠道状态、是否沿用原幂等键、是否产生第二次资金动作。

## 二、TeleAntiFraud 数据集

### 1. 规模和论文划分

论文报告的 TeleAntiFraud-28k 总规模是 **28,511 个语音—文本对**。

原论文实验划分是：

| 部分 | 数量 | 占比 |
|---|---:|---:|
| 训练集 | 21,490 | 75.38% |
| 测试集 | 7,021 | 24.62% |
| 训练集诈骗 | 9,950 | 46.30% |
| 训练集正常 | 11,540 | 53.70% |
| 测试集诈骗 | 3,697 | 52.66% |
| 测试集正常 | 3,324 | 47.34% |

这些数字来自论文正文的 `Dataset Statistics` 和 Table 1。[huggingchat/papers-content](https://huggingface.co/buckets/huggingchat/papers-content/tree/2503/2503.24115.md?utm_source=chatgpt.com)

### 2. 为什么公开下载页写成 4,000/400 和 27,146/6,807

现在的 Hugging Face 清理版把数据按任务打包，不是论文总集的同一 train/test 表：

| 包 | 训练 | 测试 | 含义 |
|---|---:|---:|---|
| `binary_classification.zip` | 4,000 | 400 | 二分类语音诈骗识别 |
| `sft.zip` | 27,146 | 6,807 | 多轮音频文本 SFT 数据 |
| `audio.zip` | — | — | 音频文件 |
| `viewer/` | — | — | 轻量预览 Parquet |

因此，**4,000/400 是公开清理版的二分类子包，不是 TeleAntiFraud-28k 的总训练测试划分**。`27,146/6,807` 是另一种 SFT 任务视图，不能与 4,000/400 相加后当成 28,511 个互斥样本。[Datasets at Hugging Face](https://huggingface.co/datasets/JimmyMa99/TeleAntiFraud?utm_source=chatgpt.com)

### 3. 许可和下载条件

- Hugging Face 数据卡标注 `Apache-2.0`，同时写有“Copyright 2025 Zhiming Ma. All rights reserved.”。[Datasets at Hugging Face](https://huggingface.co/datasets/JimmyMa99/TeleAntiFraud?utm_source=chatgpt.com)
- Hugging Face 仓库是 gated dataset。查看仓库元数据和少量预览不需要完整下载，但访问完整文件需要登录并同意向 Hugging Face 分享账户信息。[Datasets at Hugging Face](https://huggingface.co/datasets/JimmyMa99/TeleAntiFraud?utm_source=chatgpt.com)
- 完整公开包约 **12.7 GB**，其中音频压缩包约 12.7 GB。[Datasets at Hugging Face](https://huggingface.co/datasets/JimmyMa99/TeleAntiFraud?utm_source=chatgpt.com)
- GitHub README 宣称 Hugging Face 和 ModelScope 都有清理后的公开版本。ModelScope 的数据入口在项目中被列出，但 GitHub Issue #5 有用户报告曾无法通过 Git、CLI 或 SDK 下载，因此 ModelScope 当前下载可用性不能视为已核实。[GitHub](https://github.com/JimmyMa99/TeleAntiFraud?utm_source=chatgpt.com)

## 三、公开的受害人自述或转账备注数据

### PsyScam

PsyScam 从六个公开诈骗报告平台收集报告，平台包括 BBB Scam Tracker、Scamsearch、Crypto Scam Tracker、Investment Scam Tracker、Scam-Tracking Map 和 SmishTank。论文列出的原始规模分别为 10,000、204,560、291、34、1,000 和 20,295。[aclanthology.org](https://aclanthology.org/2025.findings-emnlp.675.pdf?utm_source=chatgpt.com)

数据处理后：

- D0 共 16,658 条诈骗报告。
- D1 共 1,126 条，人工标注心理操纵技术。
- D2 共 730 条，明确包含诈骗者原话或诈骗消息。
- 报告通常混合受害人叙述、诈骗者原话或两者。论文示例包含受害人对付款经过的描述。[openreview.net](https://openreview.net/pdf?id=XcL329O61T\&utm_source=chatgpt.com)

下载条件存在两层：

- 论文称完整数据集可用于研究。
- GitHub README 写明完整数据因安全和伦理原因需要研究用途申请，仓库只直接放了 `D2.csv` 样本。[KiteFlyKid/PsyScam · GitHub](https://github.com/KiteFlyKid/PsyScam?utm_source=chatgpt.com)

### CFPB Consumer Complaint Database Narratives

CFPB 的投诉叙述档案包含 2011-12-01 至 2026-08-14 期间曾公开的消费者投诉记录，并提供按月份下载的完整记录文件。它是消费者自述文本，可按金融产品、问题类型和叙述字段筛出诈骗或账户安全相关样本。[Consumer Financial Protection Bureau](https://www.consumerfinance.gov/foia-requests/foia-electronic-reading-room/cfpb-consumer-complaint-database-narratives-archive/?utm_source=chatgpt.com)

需要记录两个事实：

- CFPB 说明投诉叙述未经逐案核实，不能直接当作已确认诈骗标签。
- CFPB 已于 2026-08-14 停止继续发布新的投诉叙述和可视化，现有档案仍可使用。[Consumer Financial Protection Bureau](https://www.consumerfinance.gov/about-us/newsroom/the-cfpb-to-cease-discretionary-publication-of-complaint-narratives-and-visualizations/?utm_source=chatgpt.com)

### SynSEPA

SynSEPA 是公开的合成 SEPA 即时支付诈骗数据集，包含 `remittance_text` 转账备注字段和 `is_fraud`、`fraud_type` 标签。

- 总交易数 1,839,560。
- 诈骗交易 7,112。
- 正常交易 1,832,448。
- 10,000 个合成账户。
- 许可为 CC BY 4.0。
- 备注示例包括 `safe account transfer`、`Payment ref`、`Repayment` 等。
- 数据集明确标注为 Synthetic，真实 SEPA 诈骗数据不可公开获取。[Datasets at Hugging Face](https://huggingface.co/datasets/EpiphanyTech/SynSEPA?utm_source=chatgpt.com)

它适合构造“只给转账备注”和“转账备注加金额、收款人、时间、是否新收款人”的对照输入，不能作为真实受害人自述数据。

### Scamwatch

Scamwatch 的公开页面主要提供按类别、联系方式、支付方式和损失统计的汇总数据，并支持导出统计结果。[Scamwatch](https://www.scamwatch.gov.au/research-and-resources/scam-statistics?utm_source=chatgpt.com)

一篇研究使用了 2018-07 至 2019-07 期间的 1,015 份有经济损失的恋爱诈骗报告，其中包含受害人自由文本叙述。研究者是向 ACCC 申请获得数据，原始 1,015 条报告不是公开一键下载数据集。[Wiley Online Library](https://onlinelibrary.wiley.com/doi/10.1111/1745-9133.12645?utm_source=chatgpt.com)

### ICPSR Mass Marketing Elder Fraud Intervention

ICPSR 的 `Mass Marketing Elder Fraud Intervention, United States, 1999–2023` 提供公共使用文件，包含老年人诈骗经历调查变量、 victim records 和历史诈骗交易相关资料。公开访问不要求 ICPSR 会员机构，但研究集合中有部分文件受限，不能全部直接下载。[icpsr.umich.edu](https://www.icpsr.umich.edu/web/NACJD/studies/39001?utm_source=chatgpt.com)

公开变量包括“是否为未收到商品或服务而付款”“是否遭遇投资诈骗”等受害人自报问题。它更接近结构化受害经历和交易记录，未核实到适合 C15 的大规模中文自由叙述文本。[icpsr.umich.edu](https://www.icpsr.umich.edu/web/NACDA/studies/39001/datasets/0001/variables/B3_G2_G34_OS?archive=NACDA\&utm_source=chatgpt.com)

## 四、用于 C15 实测的输入分层

可以把测试输入单独保存为四组，避免把不同数据来源混在一个准确率里。

1. **受害人自述组**  
   使用 PsyScam 的报告文本和 CFPB 的投诉叙述，人工标记是否明确描述已经付款、是否只是收到可疑信息、是否包含收款人和转账原因。

2. **诈骗者原话组**  
   使用 PsyScam D2 中明确包含诈骗消息的样本，单独标记“仅诈骗者文本”和“受害人叙述加诈骗者文本”。

3. **转账备注组**  
   使用 SynSEPA 的 `remittance_text`，分别提供备注单独输入，以及备注加金额、时间、新收款人和跨境信息。

4. **无文本交易组**  
   只提供金额、收款人是否新出现、时间和交易频率，作为 C15 中“只有交易信息”的独立测试条件。
