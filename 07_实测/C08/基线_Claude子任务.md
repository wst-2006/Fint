# C08 基线作答（Claude 子任务）

依据：平安e生保（B）T款条款。首年免赔额1万元；等待期90天（含第90天），意外无等待期；有医保身份未经医保结算按60%赔付；床位费限1500元/日。

| 题号 | 回答 | 一句理由 |
|---|---|---|
| 1 | 2,000元 | 门诊手术属于指定门诊责任，确诊在等待期后，12,000−10,000免赔额=2,000；如果肿物其实是痣、疣这类按美容去除的良性皮肤损害，就属责任免除，赔0。 |
| 2 | 0元 | 康复医院不属于条款约定的医院（脚注6明确排除"以康复治疗为主要职能的医疗机构"）。 |
| 3 | 无法确定（5,000～50,000元） | 靶向药在赔付目录内（即有国家药监局批准文号或进口注册证）时赔60,000−10,000=50,000；不在目录内时只算15,000，赔5,000。还需要确认这种药是否在目录内。 |
| 4 | 无法确定（0或8,000元） | 晕倒如果是疾病引起的（疾病在等待期内），不算意外，赔0；如果认定为意外伤害，没有等待期，赔18,000−10,000=8,000。还需要晕倒原因的诊断结论。 |
| 5 | 2,000元 | 自付12,000−免赔额10,000=2,000（医保统筹报销的部分不能抵免赔额）。 |
| 6 | 15,000元 | 以无医保身份投保，赔付比例100%，25,000−10,000=15,000。 |
| 7 | 0元 | 血液酒精含量120mg/100ml≥80，按条款认定为醉酒，属责任免除。 |
| 8 | 0元 | 胆结石在等待期内（第45天）确诊，这种病后来产生的费用都不赔。 |
| 9 | 50,000元 | 门诊化疗属于指定门诊（门诊肿瘤治疗），60,000−10,000=50,000（化疗要求是在医院的静脉化疗）。 |
| 10 | 无法确定（0或10,000元） | 只有二级及以上、事业单位性质公立医院的普通部才赔；符合时赔20,000−10,000=10,000。还需要医院等级、性质和是否普通部。 |
| 11 | 11,000元 | 按时续保没有等待期；首年无理赔，免赔额降为9,000，20,000−9,000=11,000。 |
| 12 | 0元 | 超过60日才交费，保证续保终止、按新投保处理，等待期重新计算；第20天确诊在等待期内。 |
| 13 | 30,000元 | 团体险赔的20,000可以抵扣免赔额，抵扣后余额为0；按补偿原则最多赔50,000−20,000=30,000。 |
| 14 | 0元 | 公立医院特需部不在约定医院范围内。 |
| 15 | 10,000元 | 第二年有过理赔，第三年免赔额恢复为1万元且不再下调，20,000−10,000=10,000。 |
| 16 | 15,000元 | 第一次住院已经把1万元免赔额抵完，本保险期间内不再扣免赔额，第二次全额赔15,000。 |
| 17 | 0元 | 抑郁症属于精神和行为障碍，相关治疗属责任免除。 |
| 18 | 5,000元 | 没有检测或诊断书证明血液酒精含量≥80mg/100ml，无法认定为醉酒，按意外赔15,000−10,000=5,000。 |
| 19 | 0元（合同终止，无息退还已交保费） | 在等待期内确诊特定疾病（恶性肿瘤-重度），保险公司不承担责任，合同终止并无息退还全部保费。 |
| 20 | 0元 | 普通门诊不属于指定门诊，也不是住院前后门诊；而且800元也不够1万元免赔额。 |
| 21 | 无法确定（最多40,000元） | 单位补充医疗赔X元时，本险赔min(40,000, 50,000−X)。还需要单位补充医疗最终赔付的金额。 |
| 22 | 7,000元 | 7月5日在出院后30日内，属于住院后门诊；15,000+2,000−10,000=7,000。 |
| 23 | 7,000元 | 针灸、推拿等中医理疗不赔，扣掉3,000后，17,000−10,000=7,000。 |
| 24 | 8,000元 | 意外没有等待期，18,000−10,000=8,000；如果肇事方实际赔偿了，要按补偿原则相应扣减。 |
| 25 | 0元 | 高血压是投保前已确诊的既往症，属责任免除（还可能涉及未如实告知）。 |
| 26 | 0元 | 6,000元不够1万元免赔额；而且只做检查、诊断"未见异常"，可能被认定为不符合入院标准或体检。 |
| 27 | 0元 | 收费明显高于物价标准、且因医院原因无法医保结算，符合条款对"特需部"的第（2）项认定，不赔。 |
| 28 | 35,000元 | 床位费每天只认1,500元，共15,000；15,000+30,000−10,000=35,000。 |
| 29 | 12,000元 | 以有医保身份投保却没有经医保结算，赔付比例60%，(30,000−10,000)×60%=12,000。 |
| 30 | 9,000元 | 以有医保身份投保却没有经医保结算，赔付比例60%，(25,000−10,000)×60%=9,000。 |
| 31 | 0元 | 私立医院不在约定医院范围内。 |
| 32 | 无法确定（0或30,000元） | 甲状腺结节投保前就已知道，可能被认定为既往症或未如实告知；如果投保时如实告知且没有除外，赔40,000−10,000=30,000。还需要投保时的健康告知和核保结论（是否除外甲状腺）。 |
| 33 | 30,000元 | 医保个人账户支付的部分也算自付，40,000−10,000=30,000。 |
| 34 | 5,000元 | 7月20日距出院已超过30日，复查的门诊费不赔；只赔住院，15,000−10,000=5,000。 |
| 35 | 0元 | 等待期含第90天，第90天确诊仍在等待期内。 |
